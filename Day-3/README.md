# PlacementGPT - Day 3

PlacementGPT is an AI-powered placement preparation assistant built using Python, LangChain, and Google Gemini.

## Features

- **Career Guidance:** Provides career-related suggestions and roadmaps.
- **Conversation Memory:** Maintains conversation history using LangChain messages.
- **Prompt Engineering:** Uses system instructions and ChatPromptTemplate.
- **CSV-Based Testing:** Evaluates AI responses against expected keywords from test cases.
- **LangChain Agent:** Creates an AI agent using LangChain's create_agent.

## Technologies Used

- Python
- LangChain
- Google Gemini API
- CSV
